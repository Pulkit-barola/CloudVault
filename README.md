# CloudVault

CloudVault is a cloud-ready file management system built using Python, Streamlit, and SQLite.

## Features

- File Upload
- File Download
- File Delete
- File Search
- File Type Detection
- Storage Analytics Dashboard
- Recent Upload Tracking

## Tech Stack

- Python
- Streamlit
- SQLite
- Pandas
- Git
- GitHub

## Future Enhancements

- AWS S3 Integration
- Azure Blob Storage Integration
- User Authentication
- File Sharing System

## Run Locally

pip install -r requirements.txt

streamlit run app.py
